Espresso Machine

The Workhorse

A procedural espresso machine built from BoxGeometry for the chassis, featuring a custom GLSL shimmer shader on the body. Includes individually modelled control buttons and a clearcoat trackpad.

  • — Body: GLSL fresnel shimmer shader
  • — Display: Canvas 2D panel texture
  • — Buttons: 52 individual BoxGeometry meshes
  • — Trackpad: MeshPhysical clearcoat
