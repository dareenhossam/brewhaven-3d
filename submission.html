Deeper Understanding Statement This application demonstrates deeper understanding through four key implementations beyond the core labs: (1) A custom GLSL ShaderMaterial implementing Fresnel reflectance with animated UV shimmer on the espresso machine — written entirely from scratch in GLSL. (2) A Canvas 2D API texture generating a pressure gauge display procedurally at runtime, wrapped as THREE.CanvasTexture with zero external image dependencies. (3) GLTFLoader integration loading a Blender 5.1-exported GLB file asynchronously with DoubleSide material handling and dynamic café lighting. (4) jQuery fadeOut/fadeIn transitions for smooth model panel switching combined with requestAnimationFrame-based camera lerp animation for smooth view transitions.
Testing Evidence Tested on Chrome 124 — all features working. Tested on Safari 17 — audio requires user gesture first click. Tested on Firefox 125 — minor font rendering difference. Peer tested by classmate — confirmed drag rotation, wireframe, colour switcher and camera views all function correctly. ITS server tested — application loads without errors.
