Statement of Originality

A declaration of the original work submitted for BrewHaven, including which resources were consulted and which elements of the work are entirely my own.

01

Declaration of Own Work

Student Declaration

I confirm that this submission is my own work and has not been submitted, in whole or in part, for assessment in any other module or course of study at this or any other institution.

The BrewHaven concept, brand identity, and choice of coffee-themed models are my own original ideas. The colour palette (espresso brown, terracotta, warm cream), the CSS logo design in the header, and the written content across all four pages were not generated by AI. Every material parameter — the clearcoat values on the latte cup, the emissiveIntensity settings, the Fresnel power on the shimmer shader — was decided and tuned by me through iteration and testing.

The three 3D models — the espresso machine, iced latte, and coffee shop interior — were my own creative choices, selected because they each represent a different layer of coffee culture: the craft, the product, and the atmosphere. The overall aesthetic direction of BrewHaven is original work.

I wrote all geometry-building functions from scratch in scene.js, adapting patterns I learned from the labs and Three.js documentation. The GLSL shimmer shader, the Canvas 2D texture generation, and the GLTFLoader traversal logic for the interior sphere were all coded and debugged by me.

02

References & Resources

The following external resources were consulted during development:

  • Three.js documentation — threejs.org/docs — for geometry, material, and renderer API reference.
  • Three.js GLTFLoader documentation — threejs.org/docs/#examples/en/loaders/GLTFLoader — for loading and traversing the GLB scene graph.
  • MDN Web Docs — developer.mozilla.org — for Canvas 2D API reference (CanvasRenderingContext2D) and CSS property reference.
  • WebGL Fundamentals — webglfundamentals.org — for background understanding of vertex and fragment shader concepts used in the GLSL ShaderMaterial.
  • Google Fonts — fonts.google.com — Playfair Display and Lato typefaces, used under the Open Font Licence.

The Coffee_shop.glb file was sourced externally and used as the base geometry for the coffee shop interior scene. All procedural models (espresso machine, coffee cup with cookies) were built entirely in JavaScript with no external asset files.
